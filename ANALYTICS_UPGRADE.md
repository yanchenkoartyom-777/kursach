# Обновление аналитики - Инструкция

## Что изменилось

### 1. Админ-панель переименована в "Аналитика"
- Главная страница админа теперь `/admin/analytics` (вместо `/admin/dashboard`)
- Старый URL `/admin/dashboard` автоматически перенаправляет на новый

### 2. Расширенная аналитика
Новая страница аналитики показывает:

**Основная статистика:**
- Всего заказов
- Общая выручка
- Средний чек
- Всего автомобилей
- Доступно автомобилей
- Продано автомобилей

**Статусы заказов:**
- В ожидании
- В обработке
- Завершено
- Отменено

**Графики:**
- Тренд выручки за последние 6 месяцев (линейный график)
- Топ-5 самых продаваемых автомобилей (горизонтальная гистограмма)
- Распределение заказов по статусам (круговая диаграмма)

### 3. Раздел "Мои заказы" для клиентов
- Клиенты теперь могут видеть свои заказы по адресу `/orders`
- Ссылка "Мои заказы" добавлена в навигационное меню
- Админы видят все заказы всех клиентов в `/admin/orders`

### 4. Обновленное меню
**Админ-панель:**
- Аналитика (первый пункт)
- Автомобили
- Заказы
- Импорт/Экспорт

**Клиентское меню:**
- Каталог
- Корзина
- Мои заказы

## Как запустить

### 1. Убедитесь, что база данных запущена
```bash
docker-compose up -d
```

### 2. Примените миграции (если еще не применены)
```bash
make migrate-up
```

### 3. Запустите сервер
```bash
make run
```

Или напрямую:
```bash
go run cmd/server/main.go
```

### 4. Откройте браузер
- Админ-панель: http://localhost:8080/admin/analytics
- Клиентская часть: http://localhost:8080/

Если нужны тестовые данные для проверки аналитики:

## Отключение 2FA для быстрого входа

В файле `config.yaml` установите:
```yaml
two_factor:
  enabled: false
```

Это позволит входить без кода подтверждения.

## Возможные проблемы

### Графики не отображаются
- Убедитесь, что есть данные за последние 6 месяцев
- Проверьте консоль браузера на наличие ошибок JavaScript

### Статистика показывает нули
- Создайте несколько заказов
- Убедитесь, что заказы имеют статус "completed" для подсчета продаж

### Ошибка "template not found"
- Убедитесь, что все файлы шаблонов на месте
- Перезапустите сервер
